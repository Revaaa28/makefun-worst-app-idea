Entry for make.fun's **"The Worst App Idea Ever Pitched"**. The program writes a single original one-liner (159 characters) — a deadpan pitch for the worst, most useless app imaginable — to `/output/entry.txt`:

> Introducing ToastTrack, the app that photographs your toast every morning, ranks it against 40,000 strangers' toast, and emails you a weekly toast report card.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
